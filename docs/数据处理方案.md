## 3. 处理线①：待打标数据清洗（`tools\build_clean.py`）

**总账：47 列 − 28 删除 − 4 并入 full_text + 4 新增 = 19 列**

### 3.1 删除 28 列（理由均为实测）

| 组 | 列 | 理由 |
| --- | --- | --- |
| 互动×8 | `Titan_interaction_cnt` `reposts_cnt` `review_cnt` `like_cnt` `fav_cnt` `fans_cnt` `follow_cnt` `specie_cnt` | 平均 1 字符基本全 0，与文本标签无关 |
| 空/重复×4 | `rt_mid` `item_id` `data_typeV2` `barrage_cnt` | 填充率 0% / 与 id 重复 / 恒为["微博"] / 全"0" |
| 画像隐私×6 | `uid` `red_id` `user_region` `post_region` `gender` `birthyear` | 与文本无关，删列降合规风险 |
| 资源URL×2 | `head_url` `video_urls` | 打标用不上 |
| 冗余分类×4 | `vtype` `kol_type` `post_type` `msg_type` | `kol_tier`+`volume_type2` 已覆盖；跨平台稀疏 |
| 体积炸弹×1 | `market_seg_product_object` | P1，防"自己考自己" |
| 其他×3 | `desc` `update_time` `sentiment` | 无用；`sentiment` 是数说帖级 0/1/2 编码，与交付表"情绪"列（标签证据级规则派生）无关 |

### 3.2 合并/保留/新增

| 动作 | 列 | 说明 |
| --- | --- | --- |
| 并入 `full_text`×4 | `title`→【标题】 `cover_ocr_content`→【图片文字】 `video_highlight_content`→【视频花字】 `audio_asr_content`→【语音转写】 | 拼在【正文】前后，来源标记让模型区分"作者写的/图里 OCR 的"；空源跳过；同句重复不删（重复即重要信号） |
| 保留×15 | `id` `site_name` `publish_time` `url` `author` `is_main_post` `content` `topics` `fingerprint` `is_ad` `content_detailed_ad` `is_robot` `user_type` `volume_type2` `kol_tier` | **v1.3 起 `content`/`topics` 也经同一套去噪落盘**（避免交付表原文图标引起"没洗"误判；原文按行号回 A 永可追溯）；`is_ad`/`content_detailed_ad` 是正则方案⑤的天然对照基线，保留 |
| 新增×4 | `csv_row_no`（原始数据行号）`char_count_raw`（去噪前五源长度和）`char_count_full`（去噪后长度，判截断）`full_text` | 记账三件套支撑回溯/对账/截断 |

### 3.3 去噪规则（`denoise()` 实际执行序，v1.3）

| 步 | 规则 | 备注 |
| --- | --- | --- |
| 0 | 字面转义还原（`\x0a`/`\uXXXX`→真字符） | 在删除类规则之前 |
| 1 | 零宽字符、CRLF→LF | |
| 2 | HTML 实体解码 → 残留标签删除 | |
| 3 | 谐音符号还原（`SYMBOL_MAP`） | **必须在 emoji 删除前**，避免把有意义的替换当图标删 |
| 4 | URL 删除（含 t.cn/dwz.cn/xhslink 短链） | |
| 4b/4c | markdown 链接残骸：`[文本](…)`→`文本`；悬空 `](…` 删除 | 实测 20,861+264 字符（v1.2 漏网 1,754 行的修复） |
| 4d | 孤立半角短括号壳 `[求关注]`→`求关注`（≤12 字去壳留字） | 实测 12,750 字符；全角【】不动 |
| 5/5b | `@昵称` 删除；NFKC 归一（＠→@）后再补一遍 | |
| 6 | 话题符号 `#＃` 只删符号留文字 | |
| 7/7b | 圈号①-㊿、补充符号（℃→↑●○ 等）删除；白名单外 | |
| 7c | NFKC 花式字体归一（𝐀→A、²→2） | 必须在圈号删除后，否则 ① 会归一成 1 |
| 8/8b | emoji（含区段 1F000-1FAFF、2600-27BF、变体符）删除；星号：数字间→×，其余删 | |
| 5c/5d | **星号删除后兜底**：再过一遍 @提及 + 删除一切孤立 `@/＠`（`@水***的评论` 型粘连；邮箱型实测 0，不保留） | v1.3 |
| 8c | 连续破折号(项目符号)、残留反斜杠 | |
| 9 | 重复标点→1 个、连续 3+ 同字符→2 个（不碰数字，保护 137/30ml） | |
| 10 | 空白规范化（多空格/3+换行/首尾） | |
| 11 | 占位文本（`分享图片`/`[图片]`/`该楼层已被删除`…） | |

**红线与白名单（R5 落地）**：否定词`不/没/没有/并非/无/未/别/毫无`必须保留（否定=标签语义）；数字单位规格 `137 30ml 2% SPF50+ ×÷°%￥` 保留；成分/黑话 `麦角硫因 虾青素 双抗 早C晚A EUK-134 敏皮 k氧 k糖` 保留（`k氧/k糖` 词库未登记但语义等价"抗氧化/抗糖化"，提示词库有可补空间）。

### 3.4 行级规则

不删行；`full_text` 为空但 raw>0 → 保留记异常清单；`is_main_post`/`is_robot` 本阶段**不过滤只留列**；id 唯一性脚本断言。

## 4. 处理线②③：词库结构化 & 样本账本

| 脚本 | 输入→输出 | 要点 |
| --- | --- | --- |
| `build_lexicon.py` | 词库 csv → `data\label_lexicon.json` | 678 标签×{idx,cat,sub,label,hits,ands,excls,poss,negs,near}；`dims` 索引；幂等重跑 |
| `make_sample_list.py` | 抽样账本 → `data\抽样清单.csv` | 冒烟批从历史账本导出一次；生产批由抽样脚本直出 |

**共享规则层**（`jev_eval.py` 内实现，五方案同用、不构成方案差异）：
1. 标签反查：qid=`q`+词库行号 → 标签四件套；
2. 证据回搜：命中关键词→ 定位到【标题/正文/图片文字/视频花字/语音转写】某段 → `证据字段`+`原文证据`(±30字)；找不到=`语义命中未定位`；
3. 情绪派生：证据位置±near 窗口共现正/负向词表 → 正向/负向/混合/不适用；`情绪来源` 记账（窗口定位/未定位），汇总即"证据可定位率"。

## 5. 输出规格

### 5.1 清洗版 `data\data_export_clean_v3.csv`（19 列）

```
id, site_name, publish_time, url, author, csv_row_no, is_main_post,
char_count_raw, char_count_full, content, full_text, topics,

```
UTF-8 **BOM**、逗号、QUOTE_MINIMAL、`\n`、不带索引列。**任何 CSV 禁止 Excel 打开后另存**（P4 教训）。

### 5.2 Jev 接口文件

| 文件 | 格式 |
| --- | --- |
| `out\payloads\{样本}.jsonl` | 行=一个可 POST `/v1/systemone` 的请求体：`{sample,mode,chunk,nchunks,model,state,questions,meta}`；HTTP 实际只发 `model/state/questions` |
| `out\payloads\{样本}.text.txt/.meta.json` | 进模型全文（回搜用）+ 回溯账本（行号/截断/入样原因） |
| `out\raw\{样本}__{模式}.jsonl` | 行=一次请求完整记录：`{sample,mode,chunk,ts,http,latency_ms,est_tokens,base,sent_model,body}`（body 含官方 `answers/usage`） |

协议口径（官方文档实测）：`POST /v1/systemone`（无 chat/completions、无流式）；`jev-latest`→`jev-1.14.0`；单请求 64k tok、单问题 32k、**问题数无上限**；Noul→概率、Choice 单选≤255 选项、Score 2~10 档；计费仅输入 $0.042/M、输出免费；官方限流 100k tok/s、80 req/s。三模式实测（638 个去重问题）：A1≈27.4k tok；A2≈51.9k（单请求可容纳）；B 32问≈3.3k。

### 5.3 交付两表（`jev_eval.py` 产出，`打标结果{细分/汇总}-Jev_{模式}.csv`）

**细分 17 列**（每列生产方）：
```
样本号, 平台,            ← 输入照搬(meta)
词库原始行号,            ← 主键 = idx+1
标签ID, 类别, 细分类别, 标签  ← 词库反查(qid)
评价/提及对象, 表达类型   ← 占位"未提取"(Jev 默认不产, 可加子问补产)
情绪, 证据字段, 原文证据   ← 共享规则层派生(§4)
Jev概率                  ← ★Jev 唯一真输出(Noul 0~1)
命中阈值,                ← 管道配置(默认 0.5)
情绪来源,                ← 规则层记账(窗口定位/未定位)
模型版本, API来源         ← 请求元数据(官方/中转、1.14/1.13 可比性保险)
```
**汇总 12 列**：
```
样本号, 平台, 帖子ID（文本）, CSV记录序号, 发布时间, 文本字符数,   ← 输入照搬
入样原因,                                                      ← 抽样清单→meta 搬运
部分标签, 标签证据数,                                           ← 命中聚合
灰区待复核数,                                                   ← 概率∈[0.3,0.7] 计数(低置信转人工)
截断标记,                                                      ← char_count_full>2,000
原帖链接                                                        ← 输入照搬
```
删除列及理由：`判断说明`/`内容简述`=自由文本（Jev 不产）；`审核状态/待确认原因/未标注说明/人工判定/修订意见`=流程列，归金标准侧。空表头模板：`out\模板-打标结果*-Jev-*.csv`。

### 5.4 金标准侧纪律

列不动（16/14）；文件名带版本（v1-LLM初稿 → 人审后 v2-人审定稿）；行号为多行列表的 66 条按候选 unit 任一命中处理，人审可照 `out\金标准行号补全表.csv` 指定唯一行号；`refactor_gold.py` 负责校验/快照/模板，金标准更新后重跑一次。
