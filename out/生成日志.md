## 一、文件说明书（目录里每个东西是什么）

| 路径 | 是什么 | 谁生成 | 备注 |
| --- | --- | --- | --- |
| `data/label_lexicon.json` | 词库结构化版本：638 个概念 + 关键词/排除词 | `tools/build_lexicon.py` | 打标实际读这个；改标签体系后必须重跑并重新生成 payload |
| `data/标签体系_Jev整理版.csv` | 词库的人读版：645 行，含 TTL 汇总节点 | `tools/build_taxonomy.py` | 只是导出/反查用；改这里不影响打标 |

| `out/payloads` | 请求体目录：准备发给 Jev 的内容（生成不花钱） | `core/schemes.py` | 父目录 |
| `out/payloads/*__*__*.jsonl` | 发给 Jev 的请求 body，一行一个 HTTP 请求（超长帖会切多行） | `core/schemes.py` | 重跑同名直接覆盖；改粗筛/措辞后必须重新生成 |
| `out/payloads/*.text.txt` | 模型实际看到的正文（已按 --max-chars 截断） | `core/schemes.py` | 排查漏标时看这个；文件名不含方案名，多方案会互相覆盖 |
| `out/payloads/*.meta.json` | 溯源元信息：原始 CSV 行号、URL、字数、问题数、估算 token | `core/schemes.py` | 文件名不含方案名，多方案会互相覆盖 |
| `out/raw` | Jev 原始响应目录：每个请求的完整 body + usage + 耗时 | `core/jev_client.py` | **追加写入**，重跑不会覆盖，建议改名备份 |
| `out/raw/*.jsonl` | 一次请求一行：http 状态、answers（概率）、usage、耗时 | `core/jev_client.py` | 所有 CSV 和评测都从这里算，是唯一事实来源 |
| `out/打标明细.csv` | 只含命中标签（noul ≥ 阈值），14 列，交付用 | `tools/raw_to_csv.py` | 0 成本重导：python tools\raw_to_csv.py |
| `out/打标明细_全量.csv` | 含未命中标签，20 列，复核/评测用 | `tools/raw_to_csv.py` | 比明细多「是否命中」「灰区」两列 |
| `out/打标概览.csv` | 每帖一行：命中数、TOPIC ANGLE 前 N 个 | `tools/raw_to_csv.py` | 换阈值/改 TOP N 都只需重导，不花 token |
| `out/打标结果细分-Jev_*.csv` | 逐标签预测明细（含是否命中金标准） | `core/jev_eval.py` | tag = 方案_问法，如 B_A2 |
| `out/打标结果汇总-Jev_*.csv` | 每帖一行预测汇总 | `core/jev_eval.py` |  |
| `out/评测报告_*.md` | P/R/F1 + 分维度 + FP/FN TOP（含「未送问」标记） | `core/jev_eval.py` | 改 tau 重跑即可，0 成本 |
| `原始资料/金标准-细分-v1-LLM初稿.csv` | 参照答案：样本 × 标签 × 对象 × 证据（LLM 初稿，未经人审） | `LLM 初稿 + tools/normalize_gold.py 归一` | 改它等于改考卷，务必先备份 |
| `原始资料/金标准-细分-v1-LLM初稿.bak-*.csv` | 金标准历次备份（归一化/去重前） | `tools/normalize_gold.py` | 回滚用，确认无误后可清理 |
| `out/生成日志.md` | 本文件：文件说明书 + 当前快照 + 最近记录 | `core/genlog.py` | 自动重建，勿手改 |
| `out/生成日志.jsonl` | 日志数据源（追加），一行一条记录 | `core/genlog.py` | 删了只会丢历史记录，不影响数据 |
| `out/jev_platform_compare.csv` | Jev 可获取平台对比表（数据） | `人工调研整理` | 与打标结果无关，留档用 |
| `out/jev_platform_compare.md` | Jev 可获取平台对比表（结论） | `人工调研整理` | 与打标结果无关，留档用 |
